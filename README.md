# ElytraLimit

Автор: [zaxarik81](https://github.com/zaxarik81)

Плагин для Paper, ограничивающий горизонтальную скорость полёта на элитрах. Дополнительно доступны ограничения вертикального подъёма, Meteor Step и вертикального перемещения `.vclip`.

## Требования

- Paper 1.21.11
- Java 21 или новее для сервера

## Сборка

Установите JDK 21 и Maven, затем выполните в корне проекта:

```shell
mvn clean package
```

Готовый плагин появится в `target/ElytraLimit.jar`. GitHub Actions также собирает проект при push и pull request.

## Установка

Готовый JAR можно скачать прямо из репозитория: [ElytraLimit.jar](ElytraLimit.jar). Также его можно собрать самостоятельно командой выше. Скопируйте JAR в папку `plugins` сервера и запустите сервер. Конфигурация будет создана в `plugins/ElytraLimit/config.yml`.

## Настройка

- `max-speed-blocks-per-tick` — максимальное горизонтальное перемещение за тик; `3.0` соответствует примерно 60 блокам в секунду.
- `limit-vertical` и `max-vertical-blocks-per-second` — ограничение скорости подъёма во время полёта.
- `limit-step` и `max-step-height` — ограничение резкого подъёма вне полёта.
- `limit-vclip`, `vclip-min-distance` и `vclip-max-distance` — ограничение резкого перемещения вниз.
- `speed-warning-message` — необязательное сообщение в action bar; поддерживаются legacy-коды цветов вида `&a`.
- `enabled` — включает или отключает обработку ограничений.

После изменения конфигурации выполните `/elytralimit reload` или перезапустите сервер.

## Команда и права

- `/elytralimit reload` — перечитать конфигурацию; право `elytralimit.admin` (по умолчанию только OP).
- `elytralimit.bypass` — обход ограничений (по умолчанию выключено).
